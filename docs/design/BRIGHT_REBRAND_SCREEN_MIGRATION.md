# CraveKeep Bright Rebrand — Screen Migration Checklist

The bright coral, mint, lemon, lavender, navy, and warm-white designs are the visual source of truth. The former cream cookbook/paper interface should not remain as the default product UI.

## Rebrand foundations
- [ ] Replace the cream-first theme with the bright rebrand tokens.
- [ ] Use rounded cards, clean sans-serif typography, colorful macro treatments, and warm-white surfaces.
- [ ] Standardize navigation, buttons, chips, progress indicators, icons, image crops, and empty states.
- [ ] Keep paper/handwriting limited to onboarding and recipe-capture brand moments.
- [ ] Use Lottie for purposeful motion, while keeping text and live data native to the app.
