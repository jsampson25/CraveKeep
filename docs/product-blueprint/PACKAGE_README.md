# CraveKeep Project Package

This package contains the current product blueprint and the visual mockups created for CraveKeep.

## Structure

- `CODEX_HANDOFF.md` — start here when handing the project to Codex or a development team.
- `CraveKeep_Product_Blueprint.md` — complete product, UX, motion, screen, monetization, and phasing blueprint.
- `mockups/approved/` — current design-direction boards intended to guide implementation.
- `mockups/explorations/` — earlier studies retained for history; do not implement these as final direction.

## Approved Mockup Order

1. Logo direction
2. Logo intro animation
3. Onboarding parts 1–3
4. Capture Studio
5. Ingredient outline-to-color system
6. Recipe, nutrition, remix, and community
7. Group 1 — Home and Recipe Organization
8. Group 2 — Meal Planning and Macro Fitting
9. Group 3 — Groceries and Pantry
10. Group 4 — Cooking Experience
11. Group 5 — Account, Profile, and Household

## Status

Groups 6–8 remain to be visually completed. Their required screens are listed in the blueprint so new boards can be added without changing the established architecture.

## Starting Implementation

Give Codex the entire project folder and instruct it to read `CODEX_HANDOFF.md` before creating code. The handoff includes the source-of-truth order, technical planning requirements, vertical-slice sequence, definition of done, open decisions, and a copy/paste startup prompt.
